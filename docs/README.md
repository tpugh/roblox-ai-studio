# GitHub Pages Portfolio Site

This folder contains the static portfolio site for **Roblox AI Studio**.

- `index.html` — portfolio page (products, pipelines, accomplishments, MCP integration)
- `styles.css` — styling

## Publish

1. In the repository, open **Settings → Pages**.
2. Set **Source** to **Deploy from a branch**.
3. Select the branch to publish (e.g. `main`) and folder **/docs**.
4. Save and wait for the deployment to complete. The site will be available at the URL shown in Pages settings (typically `https://<owner>.github.io/<repo>/`).

> If GitHub Pages is not yet enabled for this repository, it must be enabled in repository settings (requires repo admin permissions).
