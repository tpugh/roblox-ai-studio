Pipeline Architecture

How work flows

  • PUSH: linear handoffs to downstream agents.
  • PULL: agents fetch required state/data before acting.
  • EVENT: async broadcasts routed through the Analytics event bus.
  • SYNC: blocking gates for high-stakes decisions and approvals.

Governance & safety

  • TOS Compliance: mandatory SYNC publish gate—nothing ships without approval.
  • Analytics hub: centralized cross-pipeline signals, memory visibility, and P0/P1 alerting.
  • Append-only memory: per-agent logs for traceability and continuous improvement.
  • Schema-driven events: registered events/subscribers in shared/schemas/events.json.

Roblox Studio MCP Integration

Connect trusted MCP clients to Roblox Studio to turn agent specs into real in-Studio actions—editing scripts, exploring the data model, running playtests, and saving work—while keeping compliance and event-bus rules intact.

Quick setup (Windows)

  1. Install/update Roblox Studio and open a place.
  2. Enable Assistant → Manage MCP Servers → Enable Studio as MCP server.
  3. Connect a client (quick connect or %LOCALAPPDATA%\Roblox\mcp.bat via stdio config) and verify the connection indicator.

What it enables

  • Script and data model operations, Luau execution, playtest and console/screen capture.
  • Asset search/insert/generation workflows and place saving.
  • Orchestrated, gated execution mapped to this repo’s agents and protocols.
